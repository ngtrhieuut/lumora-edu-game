# 07 — Parent Dashboard

## Value proposition

Phụ huynh không chỉ thấy:
“Con dùng màn hình 60 phút.”

Mà thấy:
“Trong 60 phút, con đã luyện những kỹ năng nào và mức độ tiến bộ ra sao.”

## Metrics đề xuất

- Learning time.
- Số nhiệm vụ hoàn thành.
- Mastery theo skill.
- Điểm mạnh.
- Kỹ năng cần luyện.
- Số hint đã dùng.
- Improvement trend.
- World/Chapter progress.

## Ví dụ

Tuần này:
- Thời gian học qua game: 2 giờ 05 phút
- Phép cộng: 86%
- Phép trừ: 72%
- Hình học: 91%
- Cần luyện thêm: phép trừ dạng trực quan

## Nguyên tắc

Dashboard không biến thành công cụ giám sát gây áp lực cho trẻ.
Tập trung vào:
- xu hướng,
- điểm tiến bộ,
- gợi ý hỗ trợ.
